# ふたりの「すき」予報 — 公開用ファイル

## GitHub Pagesで公開する

1. GitHubで新しい **Public repository** を作成します。
2. このフォルダの中身（`index.html` と `.nojekyll`）をリポジトリの一番上にアップロードします。
3. リポジトリの **Settings → Pages** を開き、公開元に **Deploy from a branch**、ブランチに **main**、フォルダに **/(root)** を選び **Save** します。
4. Pagesに表示されたURLを相手に送ります。

## オンライン対戦の使い方

- ふたりとも公開URLを開きます。
- 片方が「遠距離ルームを作る」を押し、表示された招待リンクを相手に送ります。
- 相手がリンクを開いて参加すると、同じ質問に回答と予想をロックして答え合わせできます。
- PeerJSのクライアントをCDNから読み込み、PeerJSのシグナリングサーバーを使います。そのためオンライン対戦にはインターネット接続が必要です。ローカル対戦はオフラインで遊べます。

全100問から毎回10問がランダムで出題されます。ゲームは静的HTMLです。サーバー側のビルドや環境変数の設定は不要です。
